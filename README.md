# Whitby Holiday Cottage

A Next.js 14 app for a Whitby holiday cottage website, built with TypeScript and Tailwind CSS.

## Getting started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Stack

- Next.js 14 App Router (`/app`)
- TypeScript
- Tailwind CSS (`tailwind.config.js`)
- Shared UI in `/components`
